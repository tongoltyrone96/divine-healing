# strawberryhope.com — landing page

The page the client's ads point to. It is a single static page with no
build step: `site/` is exactly what gets deployed.

```
site/
  index.html        all nine sections of the brief
  css/styles.css    the app's palette and type (lib/theme.dart)
  js/main.js        store routing for the Download buttons, scroll reveal
  fonts/            Playfair Display and Nunito, latin subset, self-hosted
  img/              generated by tools/make_assets.js, except badge-app-store.svg
  vercel.json       cache headers
tools/
  make_assets.js    builds site/img from the app's own artwork
  src/              sources that do not live in the app (the Google Play badge)
```

## The brief, and where the page departs from it

The brief came from the client on 2026-10-05 as WhatsApp screenshots of a
Copilot chat (kept locally in this folder, not committed). The section order
and wording follow it, except where the app does not do what the brief says.
An ad can only promise what a subscriber actually gets.

| Brief | Page | Why |
|---|---|---|
| Premium $150/year | CAD $149/year | The real price, matching both stores and Stripe |
| Premium includes monthly live meditation, priority booking, intuition development, Reiki sessions | Left out | Not in the app. Free users can book too, and Reiki in the app is an introduction plus booking |
| "Start with a free grounding meditation" | "Start with a free meditation" | Grounding is a paid session. The free ones are Anxiety Release (10 and 5 min) |
| Testimonials, 3–5 placeholders | Section held back | Made-up reviews break consumer law and ad-platform policy. Add real ones with permission |
| Practitioner photo | The emblem, in a round frame | No photo was supplied, and using someone else's photo as hers would mislead. Swap in `about__photo` |
| Built in Wix or Squarespace | Static site on Vercel | Faster for ad traffic, no monthly fee, matches the app exactly |

A footer line says the app is not a substitute for medical or mental-health
care. The brief does not ask for it; ads about anxiety and healing need it.

Screenshot 03 (the Reiki page) is not used: it says balanced energy makes
you "less likely to get sick", which is a health claim.

## Download buttons

Every Download / Get / Upgrade button carries `data-app-link`. On an iPhone
or iPad `js/main.js` points it at the App Store, on Android at Google Play.
Everywhere else, and without JavaScript, it goes to `#get-the-app`, where
both official badges are, since neither store installs onto a computer.

## Changing images

```
cd landing_page
npm install --no-save sharp
node tools/make_assets.js
```

Replace a source (a screenshot in `store/ios/`, the icon in
`divine_healing/assets/logo/`) and re-run. Nothing in `site/img` is edited by
hand.

## Previewing locally

Any static server on `site/`. Headless Chrome cannot be trusted below about
500px wide, because the desktop window has a minimum width and narrower
screenshots are crops of a wider page. Put the page in a 390px iframe to
see a real phone width.

## Domain

`strawberryhope.com` is registered at GoDaddy (nameservers
`ns55/ns56.domaincontrol.com`) and currently serves a near-empty GoDaddy
Website Builder page: a tagline, a contact form and an email sign-up.
Pointing the domain here replaces that page, so the client has to agree first.

At GoDaddy → DNS, once the Vercel project has the domain added:

| Type | Name | Value |
|---|---|---|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

Leave MX and any other records alone; email does not depend on these two.
